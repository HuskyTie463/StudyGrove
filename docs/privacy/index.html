Study Grove — Privacy Policy

Publisher: Adara Curry
Effective date: 27/09/2026

This notice describes what Study Grove’s current Windows release actually does. It is not a third-party legal website and it does not invent retention periods or provider guarantees.

Accounts and cloud study data

You can create a Firebase email/password account. Signed-in study data is stored in Google Cloud Firestore on project study-app-18492 under your user path (for example notes, tasks, events, subjects, assessments metadata, lectures, licence acceptance rows, and related nested documents). Firebase also stores the account login (email and authentication record).

Without an account, Study Grove still runs on this device. Guest licence acceptance and device settings stay local.

Assessment files

Assessment titles and attachment records can be stored in your cloud account. Files you upload are copied into this app’s local storage on the device. Those copies are not uploaded to Firestore. Files you originally chose in Documents or another folder are not deleted by the app.

If you install a different Windows package identity (for example a Microsoft Store package after a developer install), those local copies do not move automatically.

Licence acceptance records

When you accept the Software Licence Agreement, we record:
• your Firebase user id if you are signed in
• the agreement version
• the acceptance date and time
• the app version
• the exact agreement text for that version

Signed-in records are stored in Firestore under your user document, collection licenceAcceptances. Your signed-in account can create and delete those documents. They are not edited in place. Historical versions stay until you delete the account.

Without an account, the record is stored only on this device. Clearing app data or reinstalling may remove it.

After you sign in, a guest acceptance for a version that still satisfies the current required version is copied to your account so that version is not asked twice.

Study AI

Study AI is optional. A separate consent screen must be accepted before included or personal-key Study AI runs. You can withdraw in Settings. Home, Plan and Subjects still work if you decline.

If you accept, lecture text, PDFs or images, quiz or flashcard questions, and microphone audio (when you use those tools) may be sent to OpenAI and/or Anthropic.

Included Study AI (no personal key) goes through Study Grove’s signed-in Cloud Run server in australia-southeast1. That server holds the publisher OpenAI and Anthropic keys. It checks a Microsoft Store UserCollectionsId plus your Firebase sign-in token. A client “has Pro” flag is not treated as proof.

Included Voice Chat: microphone audio and tutor speech travel through that Cloud Run server, which opens the OpenAI Realtime connection on the server. The app does not receive the publisher OpenAI key.

Included text Study AI and Listen (no personal key) also go through Cloud Run to OpenAI or Anthropic.

Personal-key Study AI: a key you save is stored in this device’s secure storage (Windows Credential Locker / flutter_secure_storage). Text and Listen requests using that key go to the provider you chose and do not use the publisher keys. Personal-key Voice Chat opens a Realtime connection straight to OpenAI and does not pass through Cloud Run.

Included Study AI is limited to 40 uses per UTC calendar month while Pro is active. Voice Chat that stays connected longer than eight minutes uses an extra unit. The allowance field on your user document is written only by the server. Firestore rules prevent the app from writing it.

Microsoft subscriptions

Windows Pro is the Microsoft Store add-on studygrove_pro_monthly. Microsoft processes the purchase and can show tax in checkout. Deleting your Study Grove account does not cancel that subscription. Cancel or manage it in your Microsoft account. This notice does not state Microsoft’s refund period.

Support

Settings → Support opens https://huskytie463.github.io/StudyGrove/support/ without signing into Study Grove. If you send the form, your name, reply email, optional app/version note, and message are posted to a Cloudflare Worker, which emails them with Resend to the publisher inbox. The inbox address is not stored in the app.

Account deletion

When you delete your account, the app lists and deletes documents under your user path (including licence acceptance rows, notes, study time, and nested day tasks), then deletes the Firebase login if that cloud cleanup succeeded. If the Cloud Run URL is present, the app also asks the server to remove server-only voice session rows it can find for your user id.

App-managed copies on this device for that account (assessment file copies, uploaded avatars, wallpaper copies in app storage, temporary Listen audio) and that account’s Study AI keys and sharing consent flag are removed. Original files in your Documents folder are not deleted.

Theme, layout and other device settings that are not tied to your user id can remain on the device. Guest licence rows on the device can remain. OpenAI, Anthropic, Microsoft, Google, Cloudflare and Resend may keep their own logs or billing records. This project does not set those providers’ retention periods, and it does not confirm Cloud Run or Cloud Logging retention.

You can review the current Software Licence Agreement in Settings.
