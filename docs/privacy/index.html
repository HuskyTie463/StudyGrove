Study Grove — Privacy Policy

Publisher: Adara Curry
Effective date: 27/09/2026

Sign-in

Study Grove asks you to create a Firebase email/password account or sign in before Home, Plan, Subjects, or the rest of the app. There is no separate unsigned planner. Before an account exists you can read this notice, accept the Software Licence Agreement, and use the sign-in screen. A licence acceptance saved then stays on the device until you sign in or clear the app.

Accounts and cloud study data

Signed-in notes, tasks, events, subjects, assessment titles and attachment records, lectures, licence acceptance rows, and related nested documents are stored in Google Cloud Firestore on project study-app-18492, under your user path. Firebase also stores the account login (email and authentication record).

Assessment files

Uploaded assessment files are copied into this app’s storage on the device. Those copies are not uploaded to Firestore. Files you originally chose in Documents or another folder are not deleted by the app. A Microsoft Store install uses a different package identity from a developer install, so those local copies do not move across by themselves.

Licence acceptance records

When you accept the Software Licence Agreement, we record your Firebase user id if you are signed in, the agreement version, the acceptance date and time, the app version, and the exact agreement text for that version. Earlier versions are not rewritten.

Signed-in records are in Firestore, collection licenceAcceptances. Your account can create and delete those documents. They are not edited in place. They stay until you delete the account.

A device-only acceptance is copied to the account after you sign in when that version still applies.

Study AI

Study AI is optional. A separate consent screen must be accepted first. You can withdraw in Settings. Home, Plan and Subjects still work if you decline.

If you accept, lecture text, PDFs or images, quiz or flashcard questions, and microphone audio (when you use those tools) may be sent to OpenAI and/or Anthropic.

Included Study AI (no personal key) goes through Study Grove’s signed-in Cloud Run server in australia-southeast1. That server holds the publisher OpenAI and Anthropic keys. It checks a Microsoft Store UserCollectionsId plus your Firebase sign-in token. A client “has Pro” flag is not treated as proof.

Included Voice Chat audio travels through that Cloud Run server, which opens the OpenAI Realtime connection. The app does not receive the publisher OpenAI key. Included text Study AI and Listen also go through Cloud Run.

A personal key you save stays in this device’s secure storage. Text and Listen requests using that key go to the provider you chose. Personal-key Voice Chat goes straight to OpenAI and does not pass through Cloud Run.

Included Study AI is limited to 40 uses per UTC calendar month while Pro is active. Starting a Voice Chat session uses one. Another use is taken every eight minutes while that session stays connected. Starting Voice Chat again, including after a timeout or reconnection, can use another. A text Study AI request or Listen request uses one when it is sent. The allowance field is written only by the server.

Microsoft subscriptions

Windows Pro is the Microsoft Store add-on studygrove_pro_monthly. Microsoft processes the purchase and can show tax in checkout. Deleting your Study Grove account does not cancel that subscription. Cancel or manage it in your Microsoft account.

What Study Grove deletes

When you delete your account in Settings, the app deletes documents under your user path, then deletes the Firebase login if that cleanup succeeded. If the Cloud Run address is present, it also asks the server to remove voice-session rows it can find for your user id.

On this device it removes that account’s assessment-file copies, uploaded avatars, wallpaper copies in app storage, temporary Listen audio, Study AI keys, and the Study AI sharing flag. Original files in Documents are not deleted. Theme and layout settings that are not tied to the user id can remain. A licence row saved on the device before the account existed can remain.

Our records, checked 27 September 2026

The Cloud Logging _Default bucket for project study-app-18492 keeps logs for 30 days. That setting applies only to logs routed to _Default, including Cloud Run logs. It does not apply to the audit logs below, and it is not a retention period for your notes.

Admin Activity, System Event, and Access Transparency audit logs are routed to the locked _Required bucket, which keeps them for 400 days. No other Cloud Logging buckets are configured on this project. The project IAM policy does not turn on Data Access audit logs.

No scheduled Firestore backups are currently configured.

The support form does not keep its own database. It emails the message to Adara Curry. Those emails have no fixed automatic expiry. Adara Curry periodically reviews them and deletes them when they are no longer needed for support, follow-up, or legitimate legal or record-keeping purposes.

Contact Adara Curry

For a privacy question, a correction, or a deletion request, open Settings → Support, or go to https://huskytie463.github.io/StudyGrove/support/ without signing in. Enter your name, a reply email, and the request. Adara Curry receives that form by email. You can also delete the account yourself in Settings.
