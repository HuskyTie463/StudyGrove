Study Grove for Mac
===================

You MUST use a freshly downloaded zip. An older copy will keep crashing.

1. Copy the whole StudyGrove folder to Desktop (not from the USB stick).
2. Double-click "Open Study Grove.command".
   If macOS blocks that, right-click it → Open → Open.
3. If it still quits, right-click Open Study Grove.command → Open, then paste this in Terminal and press Return:

   xattr -cr ~/Desktop/StudyGrove && open ~/Desktop/StudyGrove/StudyGrove.app

If macOS says "quit unexpectedly":
- In that dialog, click Report (or Show Details) and copy the text.
- Or open Console, choose Crash Reports, click StudyGrove, and copy that report.
- Please also say whether the Mac has an Apple chip (Apple M1/M2/M3/M4) or Intel.

Then:
- Right-click StudyGrove.app → Open → Open, if macOS asks.
- Allow the microphone when Voice Chat asks.
- Voice Chat and Study AI already have built-in keys. You can still paste your own in Settings.

This Mac app is not from the App Store, so macOS often blocks it once.
Do not run it directly off the USB stick.
